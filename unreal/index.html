Solo proof of concept · 2026

Field Correspondent

  • UE 5.8
  • C++
  • LLM tool calls
  • Retrieval with citations
  • AI Perception

"What was that?" answered from its own memory, cited. The F3 panel shows the hybrid search (BM25, vectors, rank fusion) and the memory pinned into the prompt.

A reporter NPC in a newspaper building that you can talk to. It talks through a language model, streamed over HTTP. It knows the building from a handbook it searches and cites. It acts by proposing an action that C++ checks before a behavior tree carries it out. And it notices what happens around it, remembers it and files dispatches that cite what it saw. It runs offline with a scripted model, or with Claude or any OpenAI-compatible server, chosen in Project Settings.

The model asks, C++ decides

  • Five tools: guide_to, follow_player, wait_here, investigate, file_dispatch. The model never moves the pawn
  • FCIntents::Route checks every call against a whitelist and the NavMesh (a complete path, not just a point on it) and refuses with a reason the model reads back: "There is no walkable way to Weather mast from here"
  • A new message aborts the running branch: "Actually, wait here" stops a guide mid-walk in about 0.2 s
  • Async HTTP with timeouts and streamed replies in both the Anthropic and OpenAI formats; no Tick on the NPC

BT_Correspondent, as built

Generated by a C++ commandlet as a real editor graph. One branch per mode, each gated by a custom Mode Is decorator that aborts both ways, so a new intent takes over at once. Six of the nodes are custom C++.

CompositeDecoratorServiceTask

Witness and report

  • World events (a delivery, a power cut) are heard through walls and seen once they happen. AI Perception turns them into timed, first-person memories
  • Memories are retrieved like handbook pages, and the newest are pinned, because "what was that?" shares no words with "I heard a knock"
  • file_dispatch is refused unless it cites a memory; the desk numbers it, saves it and posts it to a board in the level

Measured

Headless on a Ryzen 7 7700. Model latency isn't here: with no API key or local model available, model calls ran against the offline script and a local test server.

Solo project · 2026

Ashford Hollow

  • UE 5.8
  • C++
  • Gameplay Ability System
  • 2–4 players, server-authoritative
  • 5 streamed zones

The Hollow Abbot's second phase: Pyre Rain fills a circle under each player while the dead around the chamber rise. The phase is one replicated byte; every client derives the new form from it. A replay frame.

A medieval top-down pixel-art RPG slice for two to four players over a listen or dedicated server, across five streamed zones: a village, a forest with a hidden glade, a ruined watchtower, Blackmere Marsh and the Old Abbey Crypt. The server decides every outcome; clients predict only what makes the game feel instant. Every gameplay system is C++, every map and behavior tree is generated by editor commandlets, and art came from a CC0 pack.

Enemy AI

  • One AAHEnemyAIController with AI Perception (sight) and a behavior tree per enemy type, all sharing one Blackboard
  • Wolf pack: flank slots and per-target attack tokens, so only one wolf bites at a time
  • Bandit archer: an EQS query picks a firing spot that is in range, in sight and reachable; kiting falls out of that
  • Mini-boss: telegraphed slam and lane dash, with an observer abort that cuts the chase the moment an attack fits
  • Two-phase boss: phases are data (health threshold, look, moveset, granted abilities). At half health the Hollow Abbot ignites, wakes the dead and gains Pyre Rain. One tree serves both phases: the new attack simply fails until it's granted
  • Ambushers: kappas wait under the bog water and skeletons lie as bones, then surface as a pack when you come close
  • Statuses the AI respects: any stun-type status (a stun, a kappa submerged, a boss transforming) holds the brain still, with no AI code per status
  • NavMesh pathing with Detour crowd avoidance, so packs flow around each other; burning ground is a NavMesh obstacle they path around

NPCs and quests

Lag compensation, measured

The server rewinds melee targets by the attacker's round trip. A scripted client swung at three circling wolves for 25 s; a ghost hit is a spark the client showed that the server then rejected.

Prediction, measured

Server corrections of a player's predicted movement, 100 ms each way, scripted runs.

Soft collision: players walk through enemies, the server moves enemies aside (25 s wolf fight)534121
Bog water slows you, predicted from where you stand1840

What's left in the fight is knockback, which a client can't predict. A dedicated server with every zone loaded spends about 1.5 ms a tick; a two-player boss fight costs 4.5 to 7.8 KB/s per client.
